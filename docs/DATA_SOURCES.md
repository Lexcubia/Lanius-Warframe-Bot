# 数据源说明

Lanius **仅在 `apps/api` 适配层**访问上游；bot / web / admin 只调 Lanius API。

| 源                                                                            | 用途                                                                                                                   | 备注                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ----------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Warframe 官方 `worldState.php`                                                | 世界状态 / 裂隙 / 入侵 / 午夜电波 / 虚空商人 / 瓦奇娅 / 突击 / 执行官 / 回廊 / 赏金 / 警报 / 科研 / **Wave1 日常切片** | MVP：`realm=international`。既有切片外，Wave1 另映射：`DailyDeals`（达沃）、`Events`（新闻）、`Goals`（限时活动）、`ProjectPct`（舰队建造）、`VoidStorms`（九重天）、`PVPChallengeInstances`（武形秘仪）、`WeeklyVaultBonusRewards`（氏族）、`FlashSales`（商城闪购）、`KnownCalendarSeasons`（1999 日历）、`Descents`（沉沦之地）。官方 JSON **无**独立 Arbitrations / 赤毒虹吸 / 钢路侵袭。                                                                                                           |
| Warframe 官方 PublicExport CDN（`content.warframe.com`）                      | 武器 / 物品图标图床                                                                                                    | URL 由 API 写入 DTO 的 `iconUrl`，客户端直链官方 CDN（如 `.../StoreIcons/Weapons/...png!hash`）                                                                                                                                                                                                                                                                                                                                                                                                         |
| 仓库内 `packages/ui/assets/elements/*.png`                                    | 信条/终幕 Valence 元素图标                                                                                             | 本地资产（冲击/火焰/冰冻/电击/毒素/磁力/辐射）；**不是**官方 Damage CDN                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 仓库内 `apps/api/src/adapters/worldstate/data/*`                              | Wave1 静态种子                                                                                                         | `synth-targets.json`（结合目标，DE 不下发）；`steel_shop.json` / `palladino_shop.json`（钢精/碎银，wiki 口径）；`rotations-wave1.json`（灵化周循环 + 言录使候选池）；`arb-ratings.json`（仲裁社区实测中位数，补 arbi tierlist 空白）                                                                                                                                                                                                                                                                    |

| [warframestat.us](https://docs.warframestat.us/)（WFCD）`GET /pc/arbitration` | 当前仲裁节点（社区源）                                                                                                 | 官方 worldState 无仲裁字段；**仅 API 适配层** → `WorldstateDto.arbitration`。失败时 `null`，不拖垮 `/v1/worldstate`。                                                                                                                                                                                                                                                                                                                                                                                   |

| 赤毒 / 血紊虹吸                                                               | `/赤毒`                                                                                                                | 原社区源 10o.io **已停摆**；官方不下发。`WorldstateDto.kuva` 返回空 missions + `sourceNote`（对齐 SDJK 策略）。                                                                                                                                                                                                                                                                                                                                                                                         |
| [Warframe Market](https://warframe.market/) API                               | `/wm` 在线卖单排行、`/zk` 在线紫卡拍卖                                                                                 | 社区源；**默认 v2**（`/v2/items`、`/v2/item/{slug}`、`/v2/orders/item/{slug}`、`/v2/riven/weapons`）。v1 物品/订单已弃用（404/403 Deprecated）。紫卡拍卖暂仍走 v1 `/auctions/search`（v2 尚无对等路由）。请求须带可识别 `User-Agent`（`Lanius-Warframe-Bot …`）+ `Accept` / `Language` / `Platform`；缺 UA 时 Cloudflare 对 Node fetch 返回 403 挑战页。名称取自 v2 `i18n`；订单映射 `rank`→`mod_rank`、`ingameName`、`status`、`reputation`；物品详情透出 `ducats` / `setParts`；结果经 Redis TTL 缓存 |
| SQLite `rotation_schedules`                                                   | 信条 / 终幕**当期货架**（`items_json` 全部平级展示）                                                                   | admin 可改 epoch / `periodDays`（通常 4）/ 货架列表；Valence 元素与百分比官方 worldState **不含**，需按游戏内或 wiki 人工维护                                                                                                                                                                                                                                                                                                                                                                           |
| 捆绑 `apps/api/src/data/name-bilingual.json`                                  | `/翻译`、`/wiki` 名称锁定                                                                                              | **DE Public Export** language 同键对精简（Mods/Weapons/Suits/Items 等命名空间；排除描述类键尾）。源自 SDJK `build_name_bilingual` 同口径；**仅 API 层**加载。**不**收录社区外号；wm/zk 仍只用 WFM `i18n` 名                                                                                                                                                                                                                                                                                             |
| [灰机维基](https://warframe.huijiwiki.com/)                                   | `/wiki` **深链 / 搜索 URL**                                                                                            | **不做全文镜像**；API 只拼页面或搜索链接 + 短简介行（玩法词 / 官方双语名对照）。客户端仍只调 Lanius                                                                                                                                                                                                                                                                                                                                                                                                     |
| 本地效价融合公式（`packages/core` valence）                                   | `/武器融合`                                                                                                            | 对齐 SDJK / 官方 wiki Valence Fusion：`1.1×max` 向下一位小数，≥58% 进位 60%；元素二选一不合成。元素图标仍用仓库内 `packages/ui/assets/elements/*.png`                                                                                                                                                                                                                                                                                                                                                   |

缓存与持久化：

- **Redis**：上游规范化结果 TTL（不可用时内存降级，`/v1/health` → `cache=degraded`）
- **SQLite**：模块开关、帮助菜单、ACL、调用审计、**订阅推送**、轮换表
